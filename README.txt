LOVE MISSION — προσωπικό mini game συγγνώμης ❤️

ΠΩΣ ΝΑ ΤΟ ΔΟΚΙΜΑΣΕΙΣ
1. Άνοιξε τον φάκελο LoveMission.
2. Κάνε διπλό κλικ στο index.html.
3. Θα ανοίξει στον browser σου.

ΠΩΣ ΝΑ ΤΟ ΠΡΟΣΩΠΟΠΟΙΗΣΕΙΣ
Άνοιξε το index.html με VS Code και αναζήτησε:
- const heartMessages = [...] για τα μηνύματα στις καρδιές
- const apologyLetter = `...` για το τελικό γράμμα
Άλλαξε το κείμενο με δικά σου λόγια και πάτησε Ctrl+S.

ΠΩΣ ΝΑ ΤΟ ΑΝΕΒΑΣΕΙΣ ΩΣ LINK ΜΕ GITHUB PAGES
1. Σύνδεση στο https://github.com
2. Δημιούργησε νέο Public repository με όνομα LoveMission.
3. Add file → Upload files → ανέβασε το index.html → Commit changes.
4. Settings → Pages → Build and deployment: Deploy from a branch.
5. Branch: main, Folder: /(root) → Save.
6. Περίμενε λίγα λεπτά. Το link θα είναι:
   https://YOUR-USERNAME.github.io/LoveMission/
   (αντικατάστησε το YOUR-USERNAME με το username σου)

ΣΗΜΑΝΤΙΚΟ
Το repository είναι δημόσιο, άρα ο κώδικας μπορεί να διαβαστεί από άλλους.
Μην προσθέσεις ιδιωτικές πληροφορίες που δεν θέλεις να είναι δημόσιες.
Το παιχνίδι είναι ένα μικρό δώρο· άφησε χώρο στην κοπέλα σου να νιώσει και να απαντήσει όπως θέλει.
